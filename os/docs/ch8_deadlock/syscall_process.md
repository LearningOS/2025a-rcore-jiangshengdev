# syscall/process.rs 改动详解

## 1. 目标

补丁实现了之前未完成的 `sys_get_time` 系统调用，使用户态能够安全地获取当前时间并写入 `TimeVal` 结构体指针，即便该结构体跨越页边界。

## 2. 原始问题

旧实现直接返回 `-1`，未完成：

- 没有时间来源；
- 没有处理用户指针跨页；
- 没有写入数据的内存安全保障。

## 3. 新增与修改点

| 元素                                           | 用途                                   |
| ---------------------------------------------- | -------------------------------------- |
| 引入 `get_time_us()`                           | 获取以微秒为单位的时间戳               |
| 引入 `translated_byte_buffer(token, ptr, len)` | 支持跨页拆分写入用户空间缓冲区         |
| 局部构建 `TimeVal` 并按字节切片拷贝            | 避免直接写用户指针导致部分页缺失时出错 |
| 空指针检查 `if ts.is_null()`                   | 防御式编程，避免访问非法地址           |
| 返回值：成功 `0` / 失败 `-1`                   | 与其他系统调用错误语义保持一致         |

## 4. 拷贝流程详解

1. 获取时间（微秒）并拆分为 `sec = micros / 1_000_000` 与 `usec = micros % 1_000_000`。
2. 将本地栈上 `TimeVal` 转成 `&[u8]` 原始字节视图。
3. 构造迭代器：`translated_byte_buffer(token, ts as *const u8, size_of::<TimeVal>())`，该迭代器返回多个可写切片，对应用户态的实际物理页映射范围。
4. 逐段复制：维护一个 `offset`，对每段做 `buf[..copy_len].copy_from_slice()`。
5. 若最终复制字节数 `== size_of::<TimeVal>()` 返回 0，否则返回 -1。

## 5. 跨页场景示例

若 `TimeVal*` 位于页尾，例如只剩 4 字节空间，而结构体大小（假设为 16 字节）跨越到下一页：

- 迭代器将提供两段缓冲区：前 4 字节 + 后 12 字节；
- 循环按顺序复制，保证数据完整写入；
- 若第二页尚未映射导致迭代器不给出该段，最终 `offset != len` 返回 -1。

## 6. 安全性与正确性

- 不直接解引用用户指针写入，避免页错误破坏内核状态。
- 分段写入确保映射缺失时不会发生部分写入后误报成功。
- 使用局部不可变切片视图，不需 `unsafe` 除了源转换（来源可信）。

## 7. 可扩展性

- 可进一步封装“写单一结构体到用户态”辅助函数，减少重复代码。
- 支持纳秒级：替换时间源与结构体字段定义。
- 支持用户态传入 `NULL` 时写入当前时间到一个全局共享页（作为优化）。

## 8. 小结

该改动完整实现了时间系统调用的语义与跨页安全拷贝逻辑，提升了用户态可用性，同时为后续其他需要写结构体到用户空间的系统调用提供了参考模式。
